Aide à l’installation

Windows affiche un avertissement ? C’est normal.

SmartScreen et le « Contrôle intelligent des applications » de Windows 11 se méfient des logiciels encore peu téléchargés. Project-On est gratuit et son code est public.

  1. SmartScreen : cliquez Informations complémentaires, puis Exécuter quand même.
  2. Fichier bloqué : clic droit sur ProjectOn_2.6.1_Setup.exe → Propriétés → cochez Débloquer en bas → OK, puis relancez l’installation.
  3. Certificat de l’éditeur (facultatif) : installez Project-On-CodeSigning.cer → Installer le certificat… → Utilisateur actuel → Autorités de certification racines de confiance. Windows reconnaîtra alors l’éditeur Elie Nyembo / Project-On sur les versions signées.

Si le Contrôle intelligent des applications bloque encore : Sécurité Windows → Contrôle des applications et du navigateur → Paramètres du contrôle intelligent des applications. Ce réglage Windows est définitif ; il ne concerne que les PC où il est actif.
