# Bêta 6 : essai guidé

Environ 30 minutes, sur `Project-On_3.0.0-beta.6_Setup.exe`. Elle s'installe à côté de la 2.8 et
travaille sur sa **copie** des données (`%APPDATA%\Project-On 3 (bêta)`) : rien de ce que vous faites
ici ne change la 2.8. Les vidéos ont besoin de FFmpeg, déjà installé sur ce poste.

Pour chaque ligne, cochez si le résultat est celui attendu ; sinon, notez ce que vous avez vu.

## La projection

| | Faire | Attendu |
|---|---|---|
| ☐ | Un verset, F2, puis **F5** (même sans vidéoprojecteur). | Plein écran comme PowerPoint ; 3 s : « Échap : revenir à la régie ». |
| ☐ | Dans la projection : → ← Espace, **B**, puis **Échap**. | Les slides avancent et reculent, B masque le texte, Échap revient à la régie. |

## Playlist et médias

| | Faire | Attendu |
|---|---|---|
| ☐ | Une playlist avec une **image** et une **vidéo** (venues de la 2.8), double-clic sur l'image puis Page suivante. | L'image en entier sur du noir ; la vidéo joue avec le son, commandes sous le moniteur (Pause, Recommencer, Boucle, Volume). |
| ☐ | Playlist → **Exporter**, puis **Importer…** le fichier de « Documents\Project-On playlists ». | Une copie de la playlist, images comprises. |
| ☐ | **Médias** (Ctrl+9) → un dossier de photos → 3 s par image → **Lancer le diaporama**. | Les images défilent en boucle ; une flèche arrête et rend le direct d'avant. |

## Cantiques

| | Faire | Attendu |
|---|---|---|
| ☐ | Cantiques → **Nouveau cantique**, deux strophes et un « Refrain », Enregistrer. | Le cantique apparaît, le refrain est reconnu ; on le projette. |
| ☐ | **Modifier**, puis **Supprimer** (confirmer). | Les changements sont gardés ; le cantique disparaît. |

## L'église

| | Faire | Attendu |
|---|---|---|
| ☐ | **Ctrl+Maj+W**, **Ctrl+Maj+P**, **Ctrl+Maj+R**. | L'accueil, l'orateur du jour, les réseaux sociaux, à vos couleurs. |
| ☐ | Réglages → **Profil de l'église** : le nom du pasteur, Enregistrer, puis Ctrl+Maj+P. | L'écran de l'orateur montre le nom. |

## Diffusion

| | Faire | Attendu |
|---|---|---|
| ☐ | **Designs** → un lower third → **L** ; **S** sur un long paragraphe, puis →. | Le lower third entre et sort ; les sous-titres avancent dans le paragraphe. |
| ☐ | Bouton **Web** → l'adresse « Diffusion » dans un navigateur (ou OBS). | Le bandeau sur fond transparent, avec le lower third. |

## Entretien

| | Faire | Attendu |
|---|---|---|
| ☐ | Réglages → **Sauvegarder maintenant**, puis **Ctrl+Maj+D**. | Une sauvegarde ; dans le contrôle avant culte, la base et la sauvegarde sont en vert (un seul écran est signalé si le vidéoprojecteur n'est pas branché). |
| ☐ | Un slide au direct, fermez la bêta par le gestionnaire des tâches, relancez. | « Reprendre le direct » remet le même slide. |
| ☐ | **Ctrl+H**. | L'historique du jour ; exports tableur et SRT. |
