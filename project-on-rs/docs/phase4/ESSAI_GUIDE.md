# Phase 4 : essai guidé de la playlist et du déroulé

Une vingtaine de minutes, sur la bêta 2 (`Project-On_3.0.0-beta.2_Setup.exe`), si possible avec le
vidéoprojecteur branché. La bêta travaille sur sa copie des données : ce que vous faites ici ne
change rien dans la 2.8. Les playlists créées dans la bêta restent dans la bêta.

Pour chaque étape, cochez si le résultat est celui attendu ; sinon, notez ce que vous avez vu.

## 1. Préparer un culte

| | Faire | Attendu |
|---|---|---|
| ☐ | **Playlist** (Ctrl+6) → **Nouvelle** → « Essai dimanche » → Valider. | La playlist apparaît, vide, choisie. |
| ☐ | **Bible** → tapez « Ps 23 » puis Entrée → clic droit sur le verset 1 → **Ajouter une plage de versets…** → de 1 à 6 → « Essai dimanche » → Ajouter. | La barre du bas annonce « 6 slides ajoutés à « Essai dimanche » ». |
| ☐ | **Cantiques** → un cantique → clic droit sur une strophe → **Ajouter tout le cantique**. | Toutes les strophes s'ajoutent, dans l'ordre. |
| ☐ | **Prédications** → un sermon → clic droit sur un paragraphe à plusieurs alinéas → **Ajouter à la playlist…** | Un seul slide : le paragraphe entier, un alinéa par ligne. |
| ☐ | **Playlist** → **Nouveau slide** → « Annonces », un texte de deux lignes → Valider. | Le slide s'ajoute à la fin, avec le genre « Slide ». |

## 2. Organiser

| | Faire | Attendu |
|---|---|---|
| ☐ | Glissez le slide « Annonces » tout en haut. | Il passe en tête ; un trait orange montrait où il allait se poser. |
| ☐ | Clic sur un verset, puis Ctrl+clic sur un autre ; Ctrl+↓. | Les deux descendent d'un cran, ensemble. |
| ☐ | Maj+clic pour choisir plusieurs slides, puis **Suppr**. | Ils disparaissent ; la barre dit « … supprimés · Ctrl+Z annule ». |
| ☐ | **Ctrl+Z**, deux fois. | La suppression, puis le déplacement, sont annulés. |
| ☐ | Clic droit sur un slide → **Dupliquer** ; puis créez une deuxième playlist et, sur le slide, **Copier vers** elle. | La copie suit l'original ; l'autre playlist reçoit le slide à la fin. |

## 3. Le déroulé

| | Faire | Attendu |
|---|---|---|
| ☐ | Ouvrez **Déroulé du culte** ; **Début prévu** : l'heure de maintenant moins 5 minutes. | — |
| ☐ | Clic droit sur le premier verset → **Commencer une section ici** → **Nouvelle section…** → « Louange », 10 min. | Un en-tête « LOUANGE · 10 min » apparaît au-dessus du verset ; un clic dessus replie la section. |
| ☐ | Faites de même sur le paragraphe de sermon : « Prédication », 30 min. | Le tableau montre les deux sections, avec leurs heures prévues. |

## 4. Pendant le culte

| | Faire | Attendu |
|---|---|---|
| ☐ | Double-clic sur le premier verset. | La playlist part au direct depuis lui ; le déroulé démarre : « Louange · … · 5:00 de retard ». |
| ☐ | Page suivante, plusieurs fois, jusqu'au paragraphe de sermon. | Les slides s'enchaînent dans l'ordre de la playlist ; au paragraphe, la section passe à « Prédication ». |
| ☐ | Regardez le paragraphe au direct (ou sur l'écran de la salle avec F5). | L'identification « Reverend William Marrion Branham » est en bas ; elle n'est pas sur les versets. |
| ☐ | Un clic sur un autre slide de la playlist, puis F2. | Le clic prépare l'Aperçu ; F2 l'envoie au direct. |
| ☐ | **Section suivante**, puis **Arrêter**. | La section change ; le suivi s'arrête. |

## 5. Pour finir

| | Faire | Attendu |
|---|---|---|
| ☐ | Fermez la bêta, rouvrez-la. | La playlist « Essai dimanche », ses sections et l'heure de début sont toujours là. |
| ☐ | Ouvrez la 2.8. | Rien n'a changé dans ses playlists. |
